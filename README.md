# JS Playground

[![Live Demo](https://img.shields.io/badge/Live-playground.js.org-yellow.svg)](https://playground.js.org/)
[![License](https://img.shields.io/badge/License-Source--Available%20View--Only-emerald.svg)](LICENSE)
[![Runtime](https://img.shields.io/badge/Runtime-Browser%20Client-blue.svg)]()

A free, browser-based JavaScript editor and playground designed for writing, executing, and testing JavaScript instantly. Featuring a DevTools-inspired console, real-time code execution, and a dedicated web development environment, JS Playground provides a lightweight coding experience without requiring an account, backend processing, or unnecessary setup.

**Live site:** [playground.js.org](https://playground.js.org/)

---

## Features

- **Instant JavaScript Execution:** Execute JavaScript directly within your browser's JavaScript engine without server-side execution or unnecessary network round trips.
- **Interactive Code Editor:** Write and edit JavaScript with syntax highlighting, bracket matching, automatic indentation, and a clean editing environment.
- **DevTools-Inspired Console:** Inspect execution results through a structured console featuring expandable objects, nested properties, array exploration, and formatted output.
- **Advanced Object Inspection:** Explore complex JavaScript objects, arrays, nested structures, and returned values through collapsible inspection trees.
- **Console Table Visualization:** Display structured data in a readable tabular format using `console.table()`.
- **Automatic Expression Evaluation:** Evaluate and display the result of the final expression without requiring an explicit `console.log()` statement.
- **Modern JavaScript Support:** Work with modern ECMAScript syntax, including arrow functions, destructuring, template literals, modules where supported, and other contemporary language features.
- **Top-Level Await:** Execute asynchronous JavaScript using `await` without manually wrapping every expression inside an asynchronous function.
- **Web API Support:** Experiment with browser-native APIs, Promises, asynchronous operations, and `fetch()` where permitted by browser security policies.
- **Dual Execution Environments:**
  - **JS Mode:** A focused environment for testing algorithms, expressions, functions, data structures, and JavaScript logic.
  - **Web Mode:** A combined HTML5, CSS3, and JavaScript environment with a live iframe preview for experimenting with complete web pages.
- **Live Web Preview:** View the results of your HTML, CSS, and JavaScript experiments directly within the playground.
- **Browser-Based Execution:** Run code locally in your browser rather than sending execution requests to a remote server.
- **No Account Required:** Start experimenting without registration, authentication, or account creation.
- **Privacy-Focused Architecture:** No analytics, tracking scripts, or server-side execution logging.
- **Lightweight Experience:** Designed to provide a straightforward coding environment without unnecessary complexity or installation requirements.
